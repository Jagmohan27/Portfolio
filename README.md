# Portfolio

Personal portfolio website showcasing my full-stack development projects and skills. Built with raw HTML, CSS, JavaScript, and animated using GSAP.

🔗 **[Live Demo](https://jagmohan27.github.io/Portfolio/)**

## Tech Stack
- HTML5, CSS3, JavaScript
- GSAP for animations

## Run Locally
To preview the site on your machine:

```bash
git clone https://github.com/Jagmohan27/Portfolio.git
cd Portfolio
npx serve .
```
