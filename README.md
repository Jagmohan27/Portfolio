# Jagmohan Yadav - Personal Portfolio

A sleek, modern, and interactive single-page personal portfolio website built with HTML, CSS, JavaScript, and GSAP animations.

## Live Demo
[https://jagmohan27.github.io/Portfolio/](https://jagmohan27.github.io/Portfolio/)

## Features
- **Immersive 3D/Canvas Background**: Interactive neural/constellation webGL canvas background that reacts to cursor movement.
- **GSAP Scroll Animations**: Smooth reveal animations and text scrambles powered by ScrollTrigger.
- **Glassmorphism UI**: Beautiful semi-transparent, blur-effect cards that adapt to the dark theme.
- **Custom Magnetic Cursor**: A tailored UX with magnetic elements (buttons and links) that snap to the cursor.
- **Fully Responsive**: Designed to look stunning on desktops, tablets, and mobile devices.

## Tech Stack
- **HTML5** & **CSS3** (Custom properties, grid, flexbox, glassmorphism)
- **Vanilla JavaScript**
- **GSAP (GreenSock Animation Platform)** for advanced animations

## Getting Started

To view the project locally, you don't need any build steps. Simply serve the directory!

1. Clone the repository:
   ```bash
   git clone https://github.com/Jagmohan27/Portfolio.git
   ```
2. Open `index.html` in your browser, or run a local server:
   ```bash
   npx serve .
   ```
